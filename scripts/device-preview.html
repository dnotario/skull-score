📱 Testing the Bonus Popup

To test the bonus popup on different devices:

  1. Click "Set Sail!" in any device frame to start the game
  2. Enter a bid and actual value (e.g., both "3") for any player
  3. Click the calculator button (🧮) that appears next to the bonus input
  4. The bonus popup will appear - test the counter buttons and see how it fits

Tip: Use the "Show Bonus Popup" button above to automatically trigger the popup in all frames!
